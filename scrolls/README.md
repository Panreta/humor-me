# scrolls

The evidence behind the project's decisions. The decisions themselves, in words, are in
[docs/decisions.md](../docs/decisions.md).

| File | What it is |
|---|---|
| [decisions.ipynb](decisions.ipynb) | Index. One line per experiment, linking to the notebook that holds it. Start here. |
| [decisions-data.ipynb](decisions-data.ipynb) | Data experiments: transcripts, rJokes (Exp 1, 2, 9–12). |
| [decisions-director.ipynb](decisions-director.ipynb) | Director experiments: simulated audience, policy comparisons (Exp 3–8, 13–16, 18). |
| [decisions-live.ipynb](decisions-live.ipynb) | Live show experiments (Exp 19 onward). |
| [decision-plot.ipynb](decision-plot.ipynb) | The same experiments as charts. |
| `decisions_common.py` | Helpers shared by the notebooks. |

For one decision: read why in `docs/decisions.md`, check the numbers in its notebook, see the chart in
`decision-plot.ipynb`.

Run all notebooks with `python scripts/run_notebook.py`.
